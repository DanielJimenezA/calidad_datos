# v8.6 — Cumplimiento de evaluaciones
Todos los porcentajes del tablero usan suma CUMPLE / suma (CUMPLE + NO_CUMPLE). Sin evaluaciones aplicables se muestra —. NO_APLICA queda excluido y visible en el detalle. No se promedian porcentajes. Se sustituyen los KPI redundantes por conteos de evaluaciones aplicables y correctas. Registros analizados sigue siendo el universo de registros del periodo, no el denominador del cumplimiento. Tabla de unidades agrupa por CLUES y entidad. CSV exporta conteos de evaluaciones. Se corrige selector mensual de reglas. No se modifica Python ni auditoría privada. Para actualizar una instalación existente copiar index.html y js/app.js, conservando los JSON actuales. Comparaciones entre periodos pueden verse afectadas por cambios de reglas o cobertura. No se ha probado en navegador ni con datos de producción actuales.
